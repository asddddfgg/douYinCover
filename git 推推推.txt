#### 如何用 Git 将修改内容同步到 GitHub（极其细致的命令行指导）

请打开您的 Windows 10 终端（CMD、PowerShell 或 Git Bash），逐行复制并粘贴运行以下命令：

Bash

```
# 1. 切换到您的本地项目目录
cd /d E:\ViralCoverImageDesign\douYinCover

------------------------------------------------

# 2. 检查当前的 git 变动情况（应能看到被修改的文件）
git status


# 3. 将所有修改暂存到本地仓库
git add .


# 4. 提交更改并写明标注内容
git commit -m "feat: 分页完成"


# 5. 推送到远程 GitHub 仓库
git push origin main


```
